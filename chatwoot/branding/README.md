# Branding externo

Os arquivos aqui são sobrepostos em `/app/public/brand-assets/` na imagem.
A regra é: **nenhum arquivo de código do Chatwoot é editado**. Se um ajuste
exigir tocar o core, ele vira uma decisão registrada em `docs/decisions/`,
porque o custo passa a ser manter merge com o upstream.

Configuração visual complementar (nome da instalação, logo, cores) é feita por
variável de ambiente e pelas Super Admin settings do próprio Chatwoot.
